**Overall Goal:**

Create an HTML page that visualizes an entity relationship graph using X3DOM. The page should include:

*   An X3DOM canvas to display the graph.
*   Controls (buttons, input field) to manipulate the graph (reset view, toggle labels, search nodes).
*   A legend explaining node types and their colors.
*   Informational messages to indicate loading status and errors.
*   Tooltips to display node information on hover (future implementation).

    *   `fetchGraphData()`:
        *   Fetches data from the `/data` endpoint using `fetch()`.
        *   Handles successful responses (parses JSON) and errors (displays messages).

        * add relationships to there element

        * Scale the Camera
    *   `addNode(node, nodeGroup)`: Creates X3DOM elements for a node (Transform, Shape, Appearance, Material, Sphere) and appends them to the `nodeGroup`. Sets the `diffuseColor` based on `getNodeColor()` and uses node positions. Set the default radio to 0.05;
